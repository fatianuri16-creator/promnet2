# Personal Website — Fatia Nuri

## 📌 Deskripsi

**Personal Website Fatia Nuri** adalah sebuah website portofolio pribadi sederhana yang dibuat sebagai bagian dari tugas mata kuliah **Pemrograman Internet (Promnet)**. Website ini dikembangkan menggunakan **HTML dasar** sebagai media untuk memperkenalkan profil, informasi diri, pengalaman pendidikan, hobi, serta beberapa proyek yang pernah dikerjakan.

Website ini juga menjadi salah satu tahap awal dalam mempelajari konsep dasar pengembangan website, khususnya penggunaan struktur HTML, navigasi antarhalaman, tabel, formulir, gambar, tautan, dan elemen-elemen HTML lainnya.

## 🎯 Tujuan

Pembuatan website ini bertujuan untuk:

* Mempelajari dasar-dasar HTML.
* Memahami struktur dasar sebuah halaman website.
* Membuat navigasi antarhalaman menggunakan HTML.
* Menampilkan informasi pribadi dalam bentuk website.
* Membuat halaman portofolio sederhana.
* Mengimplementasikan tabel dan formulir HTML.
* Mengenalkan proyek-proyek yang pernah dibuat.

## 📂 Struktur Website

Website terdiri dari beberapa halaman utama:

| Halaman        | Deskripsi                                                                       |
| -------------- | ------------------------------------------------------------------------------- |
| `home.html`    | Halaman utama yang berisi perkenalan singkat dan materi yang sedang dipelajari. |
| `about.html`   | Berisi profil, data diri, hobi, dan riwayat pendidikan.                         |
| `project.html` | Berisi daftar proyek yang pernah dikerjakan beserta teknologi yang digunakan.   |
| `contact.html` | Berisi informasi kontak dan formulir untuk mengirim pesan.                      |

## 💻 Teknologi yang Digunakan

Teknologi yang digunakan dalam pembuatan website ini meliputi:

* **HTML5** — digunakan untuk membangun struktur dan konten halaman website.
* **C++** — digunakan dalam salah satu proyek penyiram tanaman.
* **Figma** — digunakan dalam pembuatan/desain proyek Website Westra.
* **Ren'Py** — digunakan untuk pengembangan Game Kreswara Studio.

## 🚀 Fitur Website

Beberapa fitur yang terdapat pada website:

* Halaman Home sebagai halaman utama.
* Halaman About untuk menampilkan informasi pribadi.
* Halaman Project untuk menampilkan portofolio proyek.
* Halaman Contact dengan formulir kontak.
* Navigasi antarhalaman.
* Penyajian data menggunakan tabel.
* Penggunaan gambar sebagai pendukung informasi.
* Form input menggunakan berbagai jenis elemen HTML.
* Daftar riwayat pendidikan dan hobi.
